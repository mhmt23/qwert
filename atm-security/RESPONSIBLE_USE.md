# Sorumlu Kullanım (Responsible Use)

ATM-Guard bir **savunma amaçlı güvenlik / dolandırıcılık tespit** framework'üdür.

## İzin verilen kullanım
- Simülasyon ortamında zafiyet üretmek, tespit etmek, tespit yeteneğini ölçmek.
- **Yazılı ve açık yetkiye** sahip olduğunuz sistemlerde pentest/denetim.
- Kendi kurumunuzun ATM/switch/core loglarını mutabakat açısından izlemek.
- Eğitim, araştırma ve güvenlik farkındalığı.

## Yasak kullanım
- Yetkiniz olmayan herhangi bir ATM, switch veya bankacılık sistemine erişim.
- Jackpotting, black box saldırısı, XFS injection veya kart dolandırıcılığı.
- Gerçek istismar payload'ı / malware üretmek veya dağıtmak.
- Tespit ettiğiniz zafiyeti kötüye kullanmak yerine sorumlu biçimde bildirmemek.

## İlkeler
- **Yetki önce gelir:** Test öncesi kapsam ve yetki yazılı olmalı.
- **Bu repo exploit içermez:** Yalnızca zafiyetlerin bıraktığı izleri tespit eder.
- **Sorumlu ifşa:** Bulguları ilgili kuruma sorumlu biçimde bildirin.

Bu aracı kullanarak, yürürlükteki yasalara ve yalnızca yetkili kapsamda
kullanacağınıza dair sorumluluğu kabul edersiniz.
